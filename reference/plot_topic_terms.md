# Bar charts of each topic's top terms

Bar charts of each topic's top terms

## Usage

``` r
plot_topic_terms(model, n = 8)
```

## Arguments

- model:

  A model from \[topic_model()\].

- n:

  Number of terms to show per topic.

## Value

A ggplot object (add layers or save it with \[ggplot2::ggsave()\]).
