# Package index

## All functions

- [`abstract_ca()`](https://cownr10r.github.io/citelens/reference/abstract_ca.md)
  : Correspondence analysis of abstract vocabulary across time periods
- [`author_network()`](https://cownr10r.github.io/citelens/reference/author_network.md)
  : Co-authorship network analysis
- [`bib_to_df()`](https://cownr10r.github.io/citelens/reference/bib_to_df.md)
  : Read a BibTeX (.bib) file into a data frame
- [`citation_rank()`](https://cownr10r.github.io/citelens/reference/citation_rank.md)
  : Citation index and ranking
- [`citelens_stopwords()`](https://cownr10r.github.io/citelens/reference/citelens_stopwords.md)
  : Default stop words used by \`topic_model()\`
- [`cluster_maps()`](https://cownr10r.github.io/citelens/reference/cluster_maps.md)
  : Write a map for every cluster
- [`convert_refworks()`](https://cownr10r.github.io/citelens/reference/convert_refworks.md)
  : Convert a RefWorks export (Tagged Format or RIS) to a .bib file
- [`dedupe_papers()`](https://cownr10r.github.io/citelens/reference/dedupe_papers.md)
  : Remove the less-cited copy of each duplicated paper
- [`doc_similarity()`](https://cownr10r.github.io/citelens/reference/doc_similarity.md)
  : Document similarity (cosine similarity of TF-IDF vectors)
- [`fetch_abstracts()`](https://cownr10r.github.io/citelens/reference/fetch_abstracts.md)
  : Look up abstracts for a table of references
- [`find_duplicate_papers()`](https://cownr10r.github.io/citelens/reference/find_duplicate_papers.md)
  : Find papers that appear more than once in a Scholar export
- [`find_duplicates()`](https://cownr10r.github.io/citelens/reference/find_duplicates.md)
  : Find likely duplicate or near-duplicate references
- [`plot(`*`<citelens_ca>`*`)`](https://cownr10r.github.io/citelens/reference/plot.citelens_ca.md)
  : Plot an abstract correspondence analysis
- [`plot(`*`<citelens_network>`*`)`](https://cownr10r.github.io/citelens/reference/plot.citelens_network.md)
  : Plot a co-authorship network
- [`plot_cluster()`](https://cownr10r.github.io/citelens/reference/plot_cluster.md)
  : Draw one co-author cluster as a node-and-line map
- [`plot_clusters()`](https://cownr10r.github.io/citelens/reference/plot_clusters.md)
  : Several clusters on one page
- [`plot_network_overview()`](https://cownr10r.github.io/citelens/reference/plot_network_overview.md)
  : Overview plot of the whole network (dots coloured by citations)
- [`plot_similarity()`](https://cownr10r.github.io/citelens/reference/plot_similarity.md)
  : Heatmap of document similarity
- [`plot_topic_prevalence()`](https://cownr10r.github.io/citelens/reference/plot_topic_prevalence.md)
  : Bar chart of how common each topic is
- [`plot_topic_terms()`](https://cownr10r.github.io/citelens/reference/plot_topic_terms.md)
  : Bar charts of each topic's top terms
- [`plot_topic_trends()`](https://cownr10r.github.io/citelens/reference/plot_topic_trends.md)
  : Line chart of topic trends
- [`plot_word_trends()`](https://cownr10r.github.io/citelens/reference/plot_word_trends.md)
  : Line chart of word trends
- [`refworks_to_bib()`](https://cownr10r.github.io/citelens/reference/refworks_to_bib.md)
  : Convert RefWorks citations (Tagged Format or RIS) to BibTeX entries
- [`refworks_to_xlsx()`](https://cownr10r.github.io/citelens/reference/refworks_to_xlsx.md)
  : Convert a RefWorks export straight to an Excel file
- [`scholar_html_to_bib()`](https://cownr10r.github.io/citelens/reference/scholar_html_to_bib.md)
  : Convert a saved Google Scholar results page to BibTeX
- [`scholar_parse_html()`](https://cownr10r.github.io/citelens/reference/scholar_parse_html.md)
  : Parse a saved Google Scholar results page
- [`similar_to()`](https://cownr10r.github.io/citelens/reference/similar_to.md)
  : Abstracts most similar to a given one
- [`similarity_to_df()`](https://cownr10r.github.io/citelens/reference/similarity_to_df.md)
  : Similarity results as a data frame (optionally saved to Excel)
- [`topic_documents()`](https://cownr10r.github.io/citelens/reference/topic_documents.md)
  : Topic assignments for each abstract
- [`topic_k_search()`](https://cownr10r.github.io/citelens/reference/topic_k_search.md)
  : Compare different numbers of topics
- [`topic_model()`](https://cownr10r.github.io/citelens/reference/topic_model.md)
  : Topic modeling (LDA) of abstracts
- [`topic_summary()`](https://cownr10r.github.io/citelens/reference/topic_summary.md)
  : One-row-per-topic summary
- [`topic_terms()`](https://cownr10r.github.io/citelens/reference/topic_terms.md)
  : Top terms of each topic
- [`topic_trends()`](https://cownr10r.github.io/citelens/reference/topic_trends.md)
  : Topic trends over time
- [`word_trends()`](https://cownr10r.github.io/citelens/reference/word_trends.md)
  : Word trends over time
