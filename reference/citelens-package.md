# citelens: Tools for Citation Libraries and Text Analytics on Abstracts

Converts 'RefWorks' and 'RIS' exports, and saved 'Google Scholar'
results pages, to 'BibTeX', and reads 'BibTeX' files into data frames
and 'Excel' workbooks. Looks up missing abstracts in 'OpenAlex'. Runs
text analytics on abstracts: topic modeling (latent Dirichlet
allocation), cosine document similarity, and trends over time. The
computationally heavy steps are implemented in 'C++' via 'Rcpp'.
